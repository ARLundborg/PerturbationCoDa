# microbiome data
To replicate the data used in the analysis of Section 5.2 of the [paper](https://arxiv.org/abs/2311.18501), download the two files [here](https://github.com/jacobbien/trac-reproducible/tree/main/AmericanGut/original) into an `original` subfolder of this folder and run the `prep_data.R` script from this folder. This should result in two files `X_data.csv` and `meta_data.csv`, which are the files the experiment scripts read. The script uses the Bioconductor package `phyloseq`, installed with `BiocManager::install('phyloseq')`.
